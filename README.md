# Rapid Prototype: Soothsayer

Soothsayer is a tool for supporting thematic analysis of video.

*Goal 1:* To understand how much effort would be needed to develop an effective tool.

*Goal 2:* To explore technical barriers and solutions to implementing an effective tool.

## Project Values

1. _Keep political bullshit out_ - as much as possible.
2. _Don't add shit we don't need_ - features have to add real and non-trivial value for users.
3. _Don't lock users in_ - make it easy for users to abandon the product by providing many ways to export their data.
4. _Make it effective, then make it efficient, then make it feel good_ - prioritise effectiveness and efficiency over experience
5. _Make it work, then make it good_ - get the functionality working first so it can be tested and tweaked, then make it look good, i.e. _form follows function_.
